isinstance(对象, 类型),python自带函数，作用是判断某个对象是否属于指定类型，返回布尔值

JSON 顶层数据就是 JSON 文件最外层的数据类型。JSON 顶层也可以是字符串、数字、布尔值或 null，但业务项目中较少单独使用。
最外层是 {}  → Python 中是 dict
最外层是 []  → Python 中是 list

raise 是 Python 关键字，用于主动抛出异常。作用是：发现不符合要求的数据，主动报错，立即停止当前流程
常见类型：
raise TypeError("类型错误")
raise ValueError("数值或内容不符合要求")


字典取值有两种常见方式：
record["字段名"]：用于必需字段。字段不存在时会报 KeyError，适合 text、ID 等必须存在的数据。
record.get("字段名")：用于可选字段。字段不存在时返回 None，也可以设置默认值，例如 record.get("section", "未分类")。
核心区别：
字段缺失必须报错：使用 record["字段名"]
字段缺失也能继续：使用 record.get("字段名")


Python 类型注解的基本形式：  def 函数名(参数名: 参数类型) -> 返回值类型:
含义：
参数名: 参数类型
表示该参数预期接收什么类型的数据。
-> 返回值类型
表示函数预期返回什么类型的数据。
